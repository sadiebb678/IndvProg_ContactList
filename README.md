# Individual-Project-Contact-List-Web-Application
My individual project for CSCI-4830.851 Intro to Software Engineering. A web application for a list of contacts. 
This application will allow users to store the information of their contacts, view important dates such as birthdays coming up, link to emailing or messaging the person via opening the preferred application to do so, and to manage the addition or removal or editing of said contacts all in one place.
